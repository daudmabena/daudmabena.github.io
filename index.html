01 About

I am a software developer based in Dar es Salaam, Tanzania. I work on large enterprise systems, where most of my time goes into backend services, REST APIs, and integrations between systems that were not originally designed to talk to each other — including financial and payment workflows.

On the backend I work primarily with PHP, using Laravel and Yii2, backed by Oracle and other relational databases. On the front end I build interfaces with React, TypeScript, Vite, and Tailwind CSS. For mobile I use Flutter. I also handle the deployment side of the work: Linux servers, Nginx and Apache, Git workflows, and CI/CD pipelines.

I care about systems that are still maintainable after they ship — clear data models, documented APIs, predictable deployments, and code that the next developer can read.
