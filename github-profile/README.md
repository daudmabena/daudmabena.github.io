## About Me

I am a software developer based in Dar es Salaam, Tanzania. I work on large
enterprise systems, where most of my time goes into backend services, REST APIs,
and integrations between systems that were not originally designed to talk to
each other, including financial and payment workflows.

On the backend I work primarily with PHP, using Laravel and Yii2, backed by
Oracle and other relational databases. On the frontend I build interfaces with
React, TypeScript, Vite, and Tailwind CSS. For mobile I use Flutter. I also
handle the deployment side of the work: Linux servers, Nginx and Apache, Git
workflows, and CI/CD pipelines.

I care about systems that are still maintainable after they ship — clear data
models, documented APIs, predictable deployments, and code that the next
developer can read.

## Engineering Strengths

- **Backend development** — Application and domain logic in Laravel and Yii2, including background jobs, queues, and scheduled tasks.
- **Frontend development** — Component-driven React interfaces in TypeScript, with client state managed through Zustand and accessible UI built on Headless UI.
- **API design** — Consistent resource naming, request validation, predictable error responses, authentication, and versioning.
- **Database development** — Schema design, normalisation, indexing, query tuning, and stored logic on Oracle and other relational databases.
- **System integration** — Mapping data between systems, handling partial failures and retries, and keeping integrations observable when something goes wrong.
- **Software architecture** — Separating concerns into layers, keeping modules replaceable, and choosing structure that matches the size of the problem.
- **Linux and server administration** — Provisioning and maintaining Linux servers, configuring Nginx and Apache, TLS, deployments, log inspection, and backups.
